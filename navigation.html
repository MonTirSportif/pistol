Navigation

Naviguer dans le site

Cette page vous propose plusieurs façons de découvrir le contenu de MonTirSportif. Les rubriques sont les mêmes, seule la manière de les parcourir change : choisissez la variante qui vous convient, selon que vous cherchez un sujet précis ou que vous souhaitez tout découvrir pas à pas.

1
Accès direct par thèmeVous savez ce que vous cherchez : tous les thèmes sont visibles d'un coup d'œil, ouvrez celui qui vous intéresse.
2
Parcours guidé, thème après thèmeVous voulez tout découvrir : suivez les cinq préparations dans l'ordre, rubrique après rubrique.
3
Selon votre écranTéléphone, tablette, ordinateur ou papier : la navigation s'adapte à votre appareil. Découvrez les raccourcis et gestes disponibles sur chacun.

    Variante 3

    Selon votre écran

    Le site s'adapte à l'appareil que vous utilisez. Voici, pour chacun, la façon la plus pratique de naviguer. Votre écran actuel est signalé.

    Votre écran

    Téléphone

    • La barre en bas de l'écran reste toujours à portée du pouce : Accueil, Thèmes, Disciplines, Outils, Plan.
    • Dans le parcours guidé, balayez vers la gauche ou la droite pour changer de thème.
    • Le bouton ↑ remonte en haut de la page.
    Votre écran

    Tablette

    • Les tuiles s'affichent sur deux colonnes, faciles à toucher.
    • Le menu du haut défile du doigt ; « Préparation du tireur » ouvre les 5 thèmes.
    • Le balayage fonctionne aussi dans le parcours guidé.
    Votre écran

    Ordinateur

    • Touches ← → : thème précédent ou suivant dans le parcours.
    • Touches 1 à 5 : ouvrir directement un thème du parcours.
    • / : rechercher dans tout le site. Tab : se déplacer de lien en lien.
    • Sur grand écran, un sommaire flottant reste visible à gauche.
    Votre écran

    Sur papier

    • Imprimez cette page : vous obtenez la liste complète des thèmes et rubriques, à garder dans votre sac de tir.
    • Chaque page du site a aussi son bouton « Imprimer ».
